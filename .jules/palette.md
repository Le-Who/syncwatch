# Palette's Journal
## 2024-05-24 - Interruptive Overlay Accessibility
**Learning:** Interruptive overlays (Paused, Up Next, Reconnecting) frequently miss proper disabled states and explicit focus visibility (`focus-visible:ring-2`) on their interactive buttons, impacting keyboard navigability.
**Action:** Ensure all generic buttons or controls in overlays feature an `aria-label`, correct `disabled` state bindings, and visual focus styling.
