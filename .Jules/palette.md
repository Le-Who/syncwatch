# Palette's Journal
## 2024-05-24 - Accessibility Labels in Dialogs
**Learning:** Modal close buttons using generic `<X />` icons lack accessible names by default in this component library.
**Action:** Always verify icon-only buttons inside dialogs/modals have appropriate `aria-label` attributes.

## 2024-09-03 - Accessibility of Overlay Interactive Elements
**Learning:** Large, prominent interactive elements (like overlay play buttons) can easily be overlooked for accessibility because they are visually obvious.
**Action:** Always ensure large interactive overlays or visual centerpieces have proper `aria-label`s and `focus-visible` styling for keyboard navigation.
